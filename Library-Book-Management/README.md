# Library Book Management System

A REST API application developed using Java and Spring Boot.

## Features
- Add a new book
- View all books
- Search books by ID
- Update book availability
- Delete books

## Technologies Used
- Java 17
- Spring Boot
- Spring Web
- Spring Validation
- Lombok
- Maven

## API Testing
Tested using Postman.

## Project Architecture
- Model
- Service
- Controller
